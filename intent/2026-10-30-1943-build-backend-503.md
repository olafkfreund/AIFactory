# Intent: 503 with the reason when the build backend refuses a launch

Refs #1932 (slice C, #1942).

## Problem

`BuildBackendUnavailableError` (#1942) is raised when the build backend cannot
run (`AIFACTORY_BUILD_BACKEND=kubejob` without `DATABASE_URL`, or an unknown
value). The routes that start work catch it in their generic `except Exception`
and return 500 with only an error reference; the reason is only in the log.

## Proposed outcome

`POST /tasks/{id}/start` (spec creation, delegation and build paths),
`/tasks/create-and-run`, `/tasks/from-plan` (trusted-plan build) and
`/tasks/from-issue` answer 503 with the refusal reason in `detail`.

## Affected

API/UI/MCP callers of those routes on a misconfigured server. Background
callers (queue drains, process monitor, auto-fix, delegation runner) keep
logging and dropping the task, unchanged.

## Constraints

- One mapping to 503, in one place (an app-level exception handler).
- The message is our own text about server config (env var name, valid
  values); no secrets.

None.
