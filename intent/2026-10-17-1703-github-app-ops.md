# Intent: GitHub App operations: clone PATs, Copilot reviews, registration

Covers #1703, #1701 and #1702 in one change. All three are docs and operator
scripts around the GitHub App identity from #1671. #1700 (per-tenant App
credentials) is deferred until Factory RFC-0020 Phase 3.

## Problem

- #1703: a project added with a stored credential (`git_credentials`, `kind="pat"`,
  `apps/web-server/server/routes/projects.py:334-358`, used at `:570-578`)
  clones with a maintainer's PAT. The PAT is read once at clone time, rides in
  `GIT_ASKPASS` (`services/project_workspace_service.py:113-236`) and never
  pushes: pushes and PRs use the App token. It is still a long-lived
  maintainer secret at rest, usable by any org member for a clone. The
  autonomy matrix calls it "unchanged (follow-up)"
  (`docs/compliance/control-objectives.toml:78`) and the runbook says
  "Stored per-project clone PATs are unchanged"
  (`docs/docs/concepts/github-app.md:76`). Nobody has decided whether that is
  accepted, and operators are not told how to avoid it.
- #1701: `request_copilot_review`
  (`apps/web-server/server/services/pr_endgame.py:740-760`) now runs with the
  App installation token. Whether GitHub accepts a Copilot review request from
  an App token is unverified, and failure is only logged. Operators have no
  way to check it and no documented fallback.
- #1702: registering the App is manual (runbook sections 1-3): the operator
  clicks through the permissions and copies the PEM by hand.

## Proposed outcome

- The clone-PAT risk is an accepted, documented decision with its reason, and
  the runbook says how to move a project to the App token (add it with no
  stored credential, then delete the PAT).
- A probe script the operator runs once against a test PR reports whether the
  App token can request a Copilot review; the runbook gives the ruleset
  fallback when it cannot.
- A manifest and a script register the App through GitHub's manifest flow and
  write a Secret manifest file for the operator to apply. The script never
  talks to the cluster.

## Affected users and systems

Operators of an AIFactory install with the GitHub App. Files:
`docs/docs/concepts/github-app.md`, `docs/compliance/control-objectives.toml`
and the generated autonomy matrix, new scripts under `scripts/`, one test.

## Constraints

- No runtime change: no server, route or chart code changes.
- The scripts never apply anything to a cluster and never print the private key.
- The probe is run by a human, never by an agent.
- Fail closed: the scripts exit non-zero on any unexpected response.

## Open questions

None. Decisions recorded by the user on 2026-10-17 (see spec).
