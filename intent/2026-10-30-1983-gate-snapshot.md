# Intent: read every run gate once, before the first agent session

## Problem

In a kubejob build the source spec dir (`/work/.aifactory/specs/<id>`) is on
the same volume and uid as the agent's worktree, and `core/client.py` grants
the agent Write/Edit on `<project>/.aifactory/**`. A gate read before the first
agent session is safe (fresh unpack). A gate read after a session in the same
`run.py` process reads files the agent could have rewritten:

- the approval re-check before a Ctrl+C resume (`_approval_still_valid`,
  `cli/build_commands.py` ~931-944) loads `review_state.json` and
  `task_metadata.json` live;
- the QA reviewer and QA fixer model and thinking level (`qa/loop.py`, via
  `get_phase_model` / `get_phase_thinking_budget`) are read after the coder;
- the coder's own per-iteration model and thinking (`agents/coder.py` ~457)
  and the parallel coding phase (`agents/parallel_integration.py` ~458) are
  read after the planner session.

An agent can write `pinnedModel: haiku`, `thinkingLevel: none`, or a forged
approval, and the later reads honour it.

## Proposed outcome

`run.py` takes one immutable snapshot of the gate values before any agent
session: solo, require-review, the review state used for approval validity,
the run-start plan used for plan-command grants (#1940), and the task metadata
that model and thinking resolve from. Every later gate and model/thinking
lookup in that process reads only the snapshot. A forged `review_state.json` or
`task_metadata.json` written between the coder and QA changes nothing.

## Affected users and systems

AIFactory backend `run.py` build path: `cli/build_commands.py`,
`agents/coder.py`, `agents/parallel_integration.py`, `qa/loop.py`,
`phase_config.py`. kubejob and subprocess build backends. No web-server,
cluster or gitops change.

## Constraints

- Same results as today when nobody edits the files mid-run.
- Do not change the `client.py` `.aifactory/**` Write/Edit grant here; file
  the Read-only change as a follow-up.
- Stay compatible with open PR #1980 (QA/coder model from the source spec
  dir); it touches the same lines.
- Extend the #1940/#1945 run-start snapshot (`_approved_plan_snapshot`), not a
  parallel mechanism.
