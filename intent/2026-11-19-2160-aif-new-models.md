# Intent: Enable the new Claude, Codex and Antigravity models

## Problem

The model pickers (Settings > Phase Configuration, Insights, task creation) list old models: Claude Sonnet 5 / Haiku 4.5, GPT-5.x, Gemini 3.x. The owner's request (2026-11-19) is to enable the new models. The Claude shorthands `sonnet` and `haiku` still resolve to claude-sonnet-5 and claude-haiku-4-5-20251001; the insights provider list still says Opus 4.8 / Sonnet 4.6; the cost, budget, registry and cache tables have no entries for claude-sonnet-5-5, claude-haiku-5-5 or claude-fable-5-2 and carry stale prices. Codex gpt-6.x and agy gemini-4-* / gemini-3.8-flash-* are not listed at all.

## Proposed outcome

- Pickers list the new models first: Claude Fable 5.2, Opus 5.5, Sonnet 5.5, Haiku 5.5; Codex gpt-6.2-sol, gpt-6.2-astra, gpt-6.1-terra, gpt-6.1-sol, gpt-6-astra/sol/luna, gpt-5.6-sol/terra/luna; agy gemini-4-carbon/argon/neon-medium and gemini-3.8-flash-low/medium/high.
- `opus`, `sonnet`, `haiku` resolve to claude-opus-5-5, claude-sonnet-5-5, claude-haiku-5-5; `fable` resolves to claude-fable-5-2. Old ids stay pinnable (`sonnet-5`, `sonnet-4.6`, `opus-4.8`, `haiku-4.5`, ...), so saved settings and running tasks keep working.
- Every price/registry/cache table knows the new ids; prices come from the claude-api skill, and unknown OpenAI/Gemini prices stay unknown.
- gpt-6.* routes to codex and gemini-4-* to antigravity.

## Affected users and systems

AIFactory backend (phase_config, model catalog, registry, budget, enforcement, cache), web-server insights providers, frontend-web model constants, tests. Existing users with saved `sonnet`/`haiku` settings move to the new models; pinned old ids do not change.

## Constraints

- New Claude ids were proven from inside the aifactory pod with the Agent SDK on 2026-11-19 (opus-5-5, sonnet-5-5, haiku-5-5, fable-5-2 all answered).
- Do not touch project routing/registry files (wave 31 teams work there).
- No invented prices: OpenAI and Gemini prices stay null/unknown.
- Historical docs, intents, specs and changelogs are left alone.

## Open questions

None. Owner delegation 2026-11-19: take the recommended option. Provider defaults for codex (gpt-5.3-codex) and antigravity (gemini-3.5-flash) stay, because the in-image CLIs are not proven to serve the new ids; the new ids are selectable per phase.
