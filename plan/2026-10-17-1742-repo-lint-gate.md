# Plan: run the target repo's lint as a trailing gate (opt-in)

Self-contained. You do not need to open the intent or the spec. Lines are at
`4638e87d` (origin/dev). Paths under `apps/backend/` unless stated.

## Approved decisions

1. New env flag `AIFACTORY_REPO_LINT_GATE`; `1`/`true`/`yes`
   (case-insensitive) = on; anything else, or unset = **off (default)**.
   Off because a blocking lint gate can fail builds that pass today. With it
   off, behaviour is byte-identical to today.
2. Only curated commands run, never CI text:
   `flake8 -> ["flake8"]`, `ktlint -> ["ktlint"]`,
   `ruff -> ["ruff", "check", "."]`. Each lint `Gate` is named after the
   tool and has `skip_code=127` (missing tool reads `skipped` where the exit
   code survives). `eslint`, `spotless`, `detekt`, `golangci-lint`,
   `swiftlint` get no command; they stay `<name>: skipped` (#1627).
3. A lint gate that ran and failed is a normal gate failure:
   `GATE_FAILURES.md` + fix loop. That is what the operator opts into.
4. Lint gates are added before the `if not gates:` branch in `coder.py`.
5. The #1627 skip-record treats a linter as covered when any result has its
   name (skipped or not), so it is never listed twice.
6. Planner prompt gets a `## REPO LINT` section naming the allowlisted
   linters CI runs, only with the flag on and a non-empty list.
7. `ci_linters` returns `[]` when `.github/workflows` has more than 64
   `*.yml` + `*.yaml` files.
8. Forward the flag into build Jobs; document it; CHANGELOG entry.
9. Not done (recorded): descriptor `lint` lane (hub-vendored schema),
   nix-provided linter with recorded version, rewording completion banners.
   On kubejob/nixjob runners a missing linter reads *failed* (they report
   Job failure as exit 1), the same contract existing gates have there.

2. `agents/gate_runner.py`, after `detect_gates` (ends :149): add

   ```python
   # Curated lint commands (#1742). CI text never runs; others stay `skipped`.
   _LINT_COMMANDS: dict[str, list[str]] = {
       "flake8": ["flake8"],
       "ktlint": ["ktlint"],
       "ruff": ["ruff", "check", "."],
   }


   def repo_lint_enabled(env: Mapping[str, str] = os.environ) -> bool:
       """AIFACTORY_REPO_LINT_GATE opt-in: lint can fail builds that pass today."""
       return env.get("AIFACTORY_REPO_LINT_GATE", "").lower() in ("1", "true", "yes")


   def lint_gates(linters: list[str]) -> list[Gate]:
       """One gate per detected CI linter with a curated command; [] when off."""
       if not repo_lint_enabled():
           return []
       return [
           Gate(t, list(_LINT_COMMANDS[t]), skip_code=127)
           for t in linters
           if t in _LINT_COMMANDS
       ]
   ```
