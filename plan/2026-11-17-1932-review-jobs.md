# Plan: PR review and clarification as Jobs (A4, #1932)

Decisions carried from the spec: flag `AIFACTORY_REVIEW_BACKEND` (default subprocess) for both sessions; new `agent_job_backend.py` reusing `SpecJobProcess` and spec Job helpers; PR review packs a project clone, runner unpacks, pushes only `.aifactory/github/pr/review_{N}.json`, control plane fetches it with 8 MiB cap, JSON-object check, symlink and containment checks, atomic 0644 write; `scope_job_s3` after every env merge; clarification is workspace-less, no `S3_*`/`GITHUB_TOKEN`, stdout capped at 64 KiB with fail-closed parse, terminate on timeout/overflow/cancel; no fallback to in-pod on any dispatch failure; Job deadline 1800 s; an invalid `AIFACTORY_REVIEW_BACKEND` value raises `BuildBackendUnavailableError`; prerequisites checked independently of the build backend (DATABASE_URL present, `ArtifactStore()` constructible, packing and `scope_job_s3` succeed), any failure refuses with an error event; a follow-up review also ships the previous `review_{N}.json` into the clone (validated JSON object, 8 MiB cap, no symlink) because the follow-up loads it; `SpecJobProcess` gets a `truncated` flag set by `_feed` when it truncates or drops a line, and clarification treats `truncated` as the safe default; flag off leaves the existing path unchanged.
