# Plan: GitHub App operations: clone PATs, Copilot reviews, registration

Self-contained. You do not need to open the intent or the spec.

**Scope.** Docs and operator scripts only for #1703, #1701, #1702. No server,
route or chart code changes. #1700 is deferred (an issue comment, no code).

**Approved decisions (user, 2026-10-17).**

1. #1703: accept and document the stored clone PAT (clone-time read in
   `GIT_ASKPASS`, never pushes, encrypted at rest). App-token clones ride with
   #1700. PR says `Closes #1703`.
2. #1701: probe once, then document. The probe is a script the user runs;
   agents never run it. Fallback when refused: a branch ruleset that
   automatically requests Copilot review. PR says `Refs #1701`.
3. #1702: script and runbook, no web route. PR says `Closes #1702`.
4. #1700: deferred to Factory RFC-0020 Phase 3; comment on the issue.

Facts the steps rely on:

- Server mint (`apps/web-server/server/services/github_app.py:79-97`): JWT
  claims `{"iat": now-60, "exp": now+540, "iss": app_id}`, RS256 with
  `from jose import jwt`; `POST https://api.github.com/app/installations/{id}/access_tokens`
  with `Authorization: Bearer <jwt>`, `Accept: application/vnd.github+json`;
  token in `resp.json()["token"]`.
- Copilot request (`apps/web-server/server/services/pr_endgame.py:42`, `:740-760`):
  reviewer login `copilot-pull-request-reviewer[bot]`, endpoint
  `POST /repos/{owner}/{repo}/pulls/{n}/requested_reviewers`. A Copilot login
  is detected with `"copilot" in login.lower()` (`pr_endgame.py:774`).
- Clones with no stored credential already use the App token: every git call
  in `apps/web-server/server/services/project_workspace_service.py:439-470`
  runs inside `github_env` (`apps/backend/core/git_credentials.py:53`).
  Stored credentials: `DELETE /api/git-credentials/{id}`
  (`apps/web-server/server/routes/git_credentials.py:40`, `:184`).
- Chart defaults (runbook section 3): Secret `aifactory-github-app`, key
  `private-key`.

   Traps: never hand-edit the generated files; no backticks in the TOML string.

2. New `scripts/github-app-manifest.json` and `scripts/github_app_setup.py`
   (argparse, subcommands below, `main(argv=None) -> int`, `if __name__ == "__main__": sys.exit(main())`).
   - Manifest JSON: `name` "AIFactory", `url` "https://github.com/olafkfreund/AIFactory",
     `hook_attributes` `{"url": "https://example.invalid/unused", "active": false}`,
     `redirect_url` "http://localhost/", `public` false,
     `default_permissions` `{"contents": "write", "pull_requests": "write", "metadata": "read"}`,
     `default_events` `[]`.
   - `load_manifest(workflows: bool, name: str | None) -> dict`: reads the JSON
     next to the script; `workflows` adds `"workflows": "write"`; `name`
     overrides `name` (App names are global on GitHub).
   - `form_html(manifest: dict, org: str | None) -> str`: an HTML page with a
     `<form method="post">` to `https://github.com/settings/apps/new` or
     `https://github.com/organizations/{org}/settings/apps/new`, one hidden
     `<input name="manifest">` whose value is `html.escape(json.dumps(manifest))`,
     and a submit button. `org` must match `^[A-Za-z0-9-]+$` else `ValueError`.
   - `manifest --out FILE [--org ORG] [--workflows] [--name NAME]`: writes the
     page; prints "open FILE, create the App, then copy code= from the
     redirect URL (valid one hour) and run: convert CODE --out secret.yaml".
   - `secret_yaml(pem: str, name="aifactory-github-app", key="private-key") -> str`:
     `apiVersion: v1`, `kind: Secret`, `metadata.name`, `type: Opaque`,
     `stringData: {key}: |` with each PEM line indented four spaces.
   - `write_private(path, text)`: `os.open(path, O_WRONLY|O_CREAT|O_EXCL, 0o600)`;
     an existing file raises `FileExistsError` (caller prints and exits 1).
   - `convert CODE --out FILE`: `CODE` must match `^[A-Za-z0-9_-]+$`.
     `urllib.request` POST to `https://api.github.com/app-manifests/{code}/conversions`
     with `Accept: application/vnd.github+json`, timeout 30. On any HTTP or
     JSON error, or a missing `id`/`pem`/`html_url`, print the status only and
     exit 1. Write `secret_yaml(pem)` with `write_private`; print `app id`,
     `slug`, install URL `{html_url}/installations/new`, and "after install,
     the installation id is the number at the end of the settings URL; apply
     the file with kubectl yourself". Never print the PEM, client secret or
     webhook secret.
   - `copilot_listed(status: int, body: dict) -> bool`: `200 <= status < 300`
     and any `requested_reviewers[].login` with `"copilot"` in `.lower()`.
   - `probe-copilot --repo OWNER/NAME --pr N --app-id ID --installation-id ID --key-file PEM`:
     `--repo` must match `^[A-Za-z0-9_.-]+/[A-Za-z0-9_.-]+$`, ids digits.
     Import `jose` and `httpx` inside the function. Mint as the server does
     (facts above), POST `{"reviewers": ["copilot-pull-request-reviewer[bot]"]}`
     with the token, print the HTTP status and `copilot_listed`. Exit 0 if
     listed; else print "the App token cannot request Copilot; configure a
     ruleset that requests Copilot review (docs/docs/concepts/github-app.md)"
     and the first 300 chars of the response message, exit 1. Never print the
     token or key.
   Verify: `apps/backend/.venv/bin/python scripts/github_app_setup.py --help`
   and `... manifest --out /tmp/x.html` in a scratch dir. Do NOT run `convert`
   or `probe-copilot` (network, live credentials).
   Traps: standard library only at module top level (jose/httpx lazily);
   ruff clean (S310 urllib: add `# noqa: S310 - fixed https URL`); no
   secrets in output.
