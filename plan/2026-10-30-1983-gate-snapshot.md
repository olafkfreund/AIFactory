# Plan: read every run gate once, before the first agent session

## Decisions carried over from the approved spec

- One frozen dataclass `RunGates` in a new module `apps/backend/run_gates.py`.
  It is taken once in `run.py`'s build path before any agent session. Every
  later gate and model/thinking lookup in that process reads only it.
- Fields:
  - `solo: bool`
  - `requires_review: bool`: raw `requires_review_before_coding(gate_dir)`
  - `review: ReviewState`: loaded once
  - `approved_plan: dict[str, object] | None`: the #1940 snapshot, unchanged
    semantics
  - `metadata: TaskMetadataConfig`: `copy.deepcopy(load_task_metadata(gate_dir) or {})`.
    It is `{}` (never `None`) when the file is absent.
  - `cli_model: str | None`
- `gate_dir = source_spec_dir or spec_dir`.
- Methods:
  - `capture(cls, spec_dir, source_spec_dir, cli_model)`
  - `approval_valid(spec_dir)`: `not requires_review or review.is_approval_valid(spec_dir)`.
    Stored hashes, live plan hash.
  - `model(phase)`: `get_phase_model(spec_dir_unused, phase, cli_model, metadata=self.metadata)`.
    Lazy per phase (registry `deny` must not raise for unused phases).
  - `thinking_budget(phase)`
- `_approved_plan_snapshot` moves from `agents/coder.py` into
  `run_gates.py`. `agents/coder.py` re-imports it under the same name
  (`tests/test_plan_seed.py` imports it from `agents.coder`).
- Do not change `core/client.py`'s grant (follow-up #1985). Do not change the
  build pre-flight, `cli/qa_commands.py`, the planner, `qa/correction.py` or
  token attribution.
- PR #1980 (open, `fix/1969-model-from-source`) edits the same lines. Build on
  `origin/dev`; do not edit #1980's branch. Whichever merges second resolves
  the conflicts toward `gates` (`qa/loop.py` capture becomes
  `RunGates.capture(spec_dir, source_spec_dir, model)`).
