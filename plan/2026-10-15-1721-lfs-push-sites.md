## Approved decisions (carried from the spec)

- D1: one routine `lfs_upload(run, ref) -> str | None` in
  `apps/backend/core/child_env.py`; `run(argv, timeout) -> (rc, out, err)` is
  supplied by each site. Order: gate (`git grep -q -F -e filter=lfs <ref> --
  ':(glob)**/.gitattributes'`, rc != 0 -> None), get-url (rc != 0 -> None),
  `lfs_push_argv` (None -> None), config check (rc != 1 -> refusal message),
  upload with `LFS_UPLOAD_TIMEOUT = 600` (rc != 0 -> `err.strip() or "git lfs
  push failed"`). Other commands use timeout 60. `TimeoutExpired` propagates.
- D2: `push_with_lfs` and `routes/pr.py` call it; `_default_runner` gets
  `timeout: int = 120`, passed only when `runner is _default_runner`. pr.py
  error: `"Failed to push LFS objects: <err>"`.
- D3: `workspace_fetch` (ref `"HEAD"`, on error warn + return False) and
  `tfactory_client._git_info_and_push` (ref `sha`, on error warn + return
  `url, None`) call it inside `authed_push_url`, before the push, with the
  push's `git_env`.
- D4: Dockerfile apk `"git-lfs>=3.7.1"` and `RUN git lfs install --system --skip-smudge`.

- Change: add `"git-lfs>=3.7.1" \` after `git \` in the `apk add` list (keep

