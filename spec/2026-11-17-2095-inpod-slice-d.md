# Spec: guard or Job-ify the remaining in-pod agent paths (#2095, #1932 slice D)

## Design

Decision (owner delegation 2026-11-17), per path:

| Path | Choice | Why |
| --- | --- | --- |
| apply-correction | Guard now; refused in production | It is in the PARR loop, but a Job path is not sound yet (Codex review): a restarted build skips QA when QA is already approved (`should_run_qa()`), the build backend is chosen by `AIFACTORY_BUILD_BACKEND`, and the assertion-pinning check runs only in the in-pod fixer. A QA-only Job needs its own spec; filed as a follow-up. Until then production returns 409 and writes nothing. Local dev (`AIFACTORY_LOCAL_DEV=1`) is unaffected. |
| insights chat, generate-task | Guard | Interactive chat, not on a production-critical path; a Job per chat turn is a large change. |
| changelog | Guard | Occasional, owner-triggered; not critical. |
| AI conflict resolution | Guard | The merge falls back to manual conflict handling. |
| settings probe | No change | `--version` / `pgrep` with a 3 s timeout, no LLM session. |

Guard = `inpod_agent_refusal()` from `build_backend.py`, called before any spawn, off unless FORBID is
truthy and `AIFACTORY_LOCAL_DEV` is unset. Refusals are visible: apply-correction returns 409 and
writes nothing; insights emits an `insights:chunk` error; generate-task returns the refusal text;
changelog emits its error event; conflict resolution returns `success: false` with the text.

No new flag. Rollback: unset `AIFACTORY_FORBID_INPOD_AGENTS` (owner, in factory-gitops).

The apply-correction guard lives in the route, because `apps/backend` must not import `server`.

## Alternatives rejected

- Job per insights/changelog/conflict call: needs a new fetch-back contract per path, for features
  that are not production-critical.
- Job path for apply-correction now (restart the build with `QA_FIX_REQUEST.md`): unsound, see the table.
- Guard inside `qa/correction.py`: backend cannot import the server's flag helper.

## Risks

- Production behaviour change when #372 is live: the five features above are refused. Documented.
- The TFactory to AIFactory fix loop (apply-correction) is down in production until a QA-only Job exists.
