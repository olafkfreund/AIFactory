# Spec: AIFactory UI test fixes

## Design

- **B1.** `GET /env` (`apps/web-server/server/routes/context.py:439-441`)
  moves from `admin` to `viewer`. For callers below admin the response has
  `gitToken` blanked, plus any other secret-bearing field (graphiti/provider
  keys, MCP env values). The `*TokenSet` booleans stay so the UI can show
  "configured". This copies PFactory (`PF routes/context.py:393,513-517`).
  PATCH stays `admin`.
- **B3.** `oidc/provisioning.py` maps IdP groups through
  `APP_OIDC_GROUP_TO_ROLE`. It must also update the stored org role of an
  existing user on login when a mapping matches, upgrading only, never
  silently downgrading. Gitops then sets the mapping for the owner's
  Keycloak group, which the owner names or creates.
- **B4.** `api-adapter.ts:675,943`: the version comes from
  `/api/health` (`version`), cached for the session, and "unknown" on
  error.
- **B6.** The Ollama and openai-compat model fetches
  (`GeneralSettings.tsx`, `AgentProfileSettings.tsx`,
  `AgentProfileSelector.tsx`) run only when that provider is selected or has
  a base URL set.
- **B10.** `AddProjectModal.tsx`: the default mode is `clone`, with no scan
  on open. The local folder default becomes the server workspace root, and
  the scan runs only when the user picks Local.
- **B11.** `PipelineBoard.tsx:135-142` skips `stageOf(t) === 'done'` when
  computing `active`.
- **B12.** `AgentProfileSettings.tsx:47`: an unset profile shows "Auto
  (default)" with no saved selection.
- **B17.** The chat history list hides sessions with 0 messages, except
  the currently open one. The Index view shows paths relative to the
  project root.

## Alternatives rejected

- **Lowering the GET env role without redaction:** it leaks `gitToken`.
- **Giving every SSO user admin:** too broad. The group mapping is explicit.

## Risks

- B1 redaction must cover every secret field. Its test asserts that a
  member response holds no token values.
- B3 must not downgrade a manually granted admin.

## Verification

- Unit and route tests for B1 (viewer gets redacted, admin gets full,
  PATCH still admin), B3 (mapping upgrades, never downgrades) and B11 (done
  task does not light Review).
- vitest for B4, B6, B10 and B12.
- CI.
- After release, a browser re-test:
  - the MCP view and Project General without 403;
  - Settings shows the right version;
  - no 409s in the network log;
  - Add Project opens on Git URL;
  - the board's Review circle is not lit;
  - chat history has no empty sessions.
