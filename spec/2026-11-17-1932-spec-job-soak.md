# Spec: hard-disable in-pod agents outside local dev (#1930, #1932)

## Design

One predicate in `apps/web-server/server/services/build_backend.py`: `inpod_agent_refusal() -> str | None`. It returns a refusal message when `AIFACTORY_FORBID_INPOD_AGENTS` is truthy (1/true/yes/on) and `AIFACTORY_LOCAL_DEV` is not truthy; otherwise None. Default: both unset, so it returns None and nothing changes.

It is called at the subprocess boundary of the four paths, and raises `BuildBackendUnavailableError` (or, for clarification, returns the existing `skip=True` default and logs, so a task is never blocked):
- spec creation: the `else` branch of `agent_spec_creation.py` that starts the pty subprocess;
- build: just before `create_subprocess_exec` in `agent_service.py` (~1307);
- PR review: `PRReviewService.start_review` when the review backend is not kubejob;
- clarification: `generate_clarification_questions` when the review backend is not kubejob.

`log_backend_config` also logs an error at startup when the switch is on but no local-dev escape and a subprocess backend is selected for a path, so the refusal is visible before the first task.

Soak evidence (item 1): Factory#3770 proof task `167-netpol-gate-proof-3770`, Job `factory-aifactory-f-3770-spec-069bec38` Complete 1/1 in 82s; deployed image `sha-1d03c52` = v3.12.0. The factory-gitops flip of the switch is NOT in this change; it follows the soak and A4 in prod.

## Alternatives rejected

- Make forbid the default: breaks every non-k8s deployment and local dev on upgrade.
- Reuse `AIFACTORY_BUILD_BACKEND` only: it does not cover PR review or clarification.
- Separate uid / seccomp / gVisor: rejected by the owner decision of 2026-10-31.

## Risks

Turning the switch on before PR review and clarification run as Jobs would disable them; hence it ships off and the gitops flip waits for the A4 soak. Insights, changelog and the settings probe are not covered (slice D).

## Verification

Unit tests for the predicate (off by default, on, local-dev escape) and one refusal test per call site; `pytest apps/web-server/tests/` for touched files; ruff.
